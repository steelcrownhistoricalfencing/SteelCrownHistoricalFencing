# Steel Crown project instructions

Read `AGENTS.md` for repository safety and review rules.

For curriculum and document work, read `contributing/formatting-standard.md` and
`contributing/document-workflow.md`. Use the shared styles, metadata, and build
commands instead of introducing document-specific fonts, colors, or export code.

Keep website development and curriculum changes reviewable. Do not rewrite
historical claims, resolve competing interpretations, merge, or publish as an
incidental part of formatting work.
